# Aesop's Fable Visualization Game

An interactive game for children that tests their visualization skills using the classic Aesop's fable "The Tortoise and the Hare." The game presents segments of the story and asks questions about details that children should be visualizing but weren't explicitly stated in the text.

## Features

- Interactive storytelling experience
- Questions that test mental imagery skills rather than rote memorization
- Colorful gemstone collection as a reward system
- Progress tracking with a visual progress bar
- Clear, child-friendly interface
- Mobile-responsive design
- Animations for enhanced engagement

## How to Play

1. Read each segment of the story carefully
2. Answer questions about details you've visualized
3. Earn colorful gems for correct answers
4. Complete the story to see your full collection
5. Learn the moral of the fable

## Educational Benefits

- Encourages active reading
- Develops visualization skills
- Improves reading comprehension
- Teaches valuable life lessons through classic literature
- Builds critical thinking about implied information

## Technologies Used

- React
- Next.js
- Tailwind CSS
- Vercel Deployment

## Local Development

```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

## Deployment

This project can be easily deployed using Vercel:

```bash
npm install -g vercel
vercel
```

## Customization

You can customize the stories and questions by editing the `gameContent` array in `src/components/AesopGame.jsx`.
